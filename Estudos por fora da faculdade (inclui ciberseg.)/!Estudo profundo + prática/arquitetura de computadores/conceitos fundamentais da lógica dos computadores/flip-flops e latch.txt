-----O que são flip-flops?

São circuitos lógicos utilizados para guardar 1 bit utilizando de loops. Os flip-flops dependem de um clock para receber uma informação nova e armazená-la. Os latches não dependem de clock e estão constantemente esperando uma alteração na entrada para alterar seu valor armazenado.

Flip-flops a muitos anos atrás eram fisicamente quadrados planos geralmente de cor preta grandes, que utilizavam de milhões de circuitos de silício para armazenar uma certa quantia de megabits. Hoje em dia eles são extremamente menores e utilizados em inúmeros componentes elétricos computacionais.

-----Clock: Todos os computadores tem seus componentes acompanhando esse clock, o clock emite pulsos que determinam em que momento o componente deve executar uma instrução, componentes diferentes e mais antigos possuem seus clocks próprios a fim de conseguirem acompanhar o funcionamento da máquina sem dar erros. Overclock seria justamente acelerar a quantidade de pulsos por segundo em que o computador irá executar instruções.

É importante citar que os clocks não vão de 0 a 1 e de 1 a 0 instantâneamente, eles possuem bordas de subida e descida (na transição de um 1 para um 0 e vice-versa).

---Borda de subida (Rising Edge): Se trata do momento em que o clock transiciona do 0 para o 1, há uma subida imperceptível ao olho humano.

---Borda de descida (Falling Edge): É o momento em que o clock muda de 1 para 0, onde há uma descida, também imperceptível ao olho humano.

Esses intervalos de tempo das bordas são chamados de Rise Time e Fall Time, respectivamente. Geralmente duram nanossegundos.

-----Latch: A forma mais básica de um flip flop, compartilha dessa tabela verdade:

(Latch de portas NAND)

set reset   saída
1   1       não muda
0   1       q = 1
1   0       q = 0
0   0       inválida*

*produz q = nao q = 1

-----Flip-flop SR com clock:

set reset   clock   saída
0   0       subida  q0 (não muda, se estava 0, continuará 0, se estava 1, continuará 1)
1   0       subida  1
0   1       subida  0
1   1       subida  proibído/instável

a subida e descida de um pulso do clock podem resultar em resultados totalmente diferentes devido ao comprimento de ondas dos pulsos. Na descida, a tabela verdade é idêntica a tabela verdade da subida de um pulso do clock.

-----Flip-flop JK:

set reset   clock   saída
0   0       subida  q0 (não muda)
1   0       subida  1
0   1       subida  0
1   1       subida  NOT q0 (se antes era 0, vai virar 1, e vice-versa)

Usado para dar um uso a quando set e reset forem iguais a 1. Também possuí PRESET e CLEAR, são duas portas de entrada que não podem estar simultaneamente ligadas pois, PRESET ao ser ligado, dará uma saída sempre igual a 1, e CLEAR ao ser ligado, dará uma saída sempre igual a 0.

-----Flip-flop D:

Usado para armazenar 1 bit de informação. A entrada D que recebe irá aparecer na saída de clock em clock. Se não houver clock, o flip-flop D irá continuar com a entrada anterior armazenada. Os flip-flops num geral também guardam 1 bit de informação, mas a simplicidade do flip-flop D faz dele ser insubstituível até na tecnologia de hoje.
