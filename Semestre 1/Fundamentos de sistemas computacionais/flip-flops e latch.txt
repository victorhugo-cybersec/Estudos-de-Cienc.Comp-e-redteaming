-----Latch: A forma mais básica de um flip flop, compartilha dessa tabela verdade:

set reset   saída
1   1       não muda
0   1       q = 1
1   0       q = 0
0   0       inválida*

*produz q = nao q = 1

-----Clock: Todos os computadores tem seus componentes acompanhando esse clock, o clock emite pulsos que determinam em que momento o componente deve executar uma instrução, componentes diferentes antigos e mais antigos possuem seus clocks próprios a fim de conseguirem acompanhar o funcionamento da máquina sem dar erros. Overclock seria justamente acelerar a quantidade de pulsos por segundo em que o computador irá executar instruções.

-----Flip-flop SR com clock:

set reset   clock   saída
0   0       subida  q0 (não muda, se estava 0, continuará 0, se estava 1, continuará 1)
1   0       subida  1
0   1       subida  0
1   1       subida  ambíguo

a subida e descida de um pulso do clock podem resultar em resultados totalmente diferentes. Na descida, a tabela verdade é idêntica a tabela verdade da subida de um pulso do clock.

-----Flip-flop JK:

set reset   clock   saída
0   0       subida  q0 (não muda)
1   0       subida  1
0   1       subida  0
1   1       subida  NOT q0 (se antes era 0, vai virar 1, e vice-versa)

Usado para dar um uso a quando set e reset forem iguais a 1. Também possuí PRESET e CLEAR, são duas portas de entrada que não podem estar simultaneamente ligadas pois, PRESET ao ser ligado, dará uma saída sempre igual a 1, e CLEAR ao ser ligado, dará uma saída sempre igual a 0.

-----Flip-flop D:

Usado para armazenar 1 bit de informação. A entrada D que recebe irá aparecer na saída de clock em clock. Se não houver clock, o flip-flop D irá continuar com a entrada anterior armazenada.
